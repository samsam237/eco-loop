# ECO-LOOP — Notes et avancées

## Direction actuelle
- Produit de Mbôra consacré à la circularité des ressources.
- Positionnement : **donner une nouvelle valeur à ce qui existe déjà**.
- ECO-LOOP ne se limite pas au recyclage : réemploi, réparation, partage, redistribution, transformation, récupération et valorisation font partie du périmètre.
- La gestion des déchets est désormais une composante clairement visible du site, sans réduire ECO-LOOP à une simple plateforme de déchets.

## Boucle fondamentale
**Identifier → Qualifier/Comprendre → Relier → Agir → Suivre**

## Gestion des déchets
Le site présente maintenant explicitement deux moments complémentaires :
1. préserver la valeur avant que la ressource ne devienne un déchet ;
2. lorsqu'elle devient un déchet, la rendre visible, la qualifier et l'orienter vers collecte, tri, récupération, transformation ou recyclage.

## Identité visuelle
- Palette choisie pour cette version : **vert profond / teal**, avec fonds très clairs.
- Intention : environnement + circularité + confiance + technologie.
- La logique narrative de SIGNAL sert d'inspiration UX, mais ECO-LOOP conserve son identité visuelle propre.

## Prototype actuel
- Landing page + démo interactive.
- Français / anglais avec persistance via `localStorage`.
- Textes visibles et contenus générés dynamiquement traduits.

- Progression narrative : observer → qualifier → connecter → agir → suivre.

## Base stratégique
Le cahier de recherche demande d'étudier le problème profond, le cycle de vie, les modèles internationaux et africains, le Cameroun/SND30, l'Agenda 2063, les ODD, le marché, la différenciation, le modèle économique, les risques, le MVP et la relation avec SIGNAL.
